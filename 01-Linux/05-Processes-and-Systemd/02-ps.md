## Quick Cheat Sheet

| Command | Purpose |
|---|---|
| `ps` | Show current shell processes |
| `ps -ef` | Show all processes |
| `ps aux` | Detailed process listing |
| `ps -p PID -f` | Show one process |
| `ps -u USER` | Show processes by user |
| `ps -o ...` | Customize output |
| `ps --forest` | Show process hierarchy |

---

## Overview

`ps` displays a snapshot of currently running processes.

Unlike `top`, it does not continuously refresh.

Basic:

```bash
ps
```

Typical output:

```text
PID   TTY      TIME     CMD
1234  pts/0    00:00    bash
1450  pts/0    00:00    ps
```

## Common ps Formats

### Show All Processes

```bash
ps -ef
```

Useful columns include:

```text
UID
PID
PPID
CMD
```

### BSD-Style Output

```bash
ps aux
```

Useful columns include:

```text
USER
PID
%CPU
%MEM
STAT
COMMAND
```

---

## Filtering Processes

Find processes by user:

```bash
ps -u nginx
```

Show a specific PID:

```bash
ps -p 1234 -f
```

Search by name:

```bash
ps aux | grep nginx
```

A cleaner alternative:

```bash
pgrep -a nginx
```

---

## Custom Output

Show selected fields:

```bash
ps -eo pid,ppid,user,%cpu,%mem,cmd
```

Sort by CPU:

```bash
ps -eo pid,user,%cpu,%mem,cmd \
--sort=-%cpu
```

Sort by memory:

```bash
ps -eo pid,user,%cpu,%mem,cmd \
--sort=-%mem
```

---

## Process Tree

Show parent-child relationships:

```bash
ps -ef --forest
```

Example:

```text
systemd
 └─ sshd
     └─ bash
         └─ python3
```

---

## Practical Examples

Find high-CPU processes:

```bash
ps -eo pid,user,%cpu,cmd \
--sort=-%cpu | head
```

Find high-memory processes:

```bash
ps -eo pid,user,%mem,cmd \
--sort=-%mem | head
```

Inspect one process:

```bash
ps -p 1234 \
-o pid,ppid,user,stat,%cpu,%mem,cmd
```

---

## Common Pitfall

This works:

```bash
ps aux | grep nginx
```

but also matches the `grep` command itself.

Prefer:

```bash
pgrep -a nginx
```

when you only need matching processes.

## Conclusion

`ps` is the standard tool for taking a snapshot of Linux processes.

The two most useful forms are:

```bash
ps -ef
ps aux
```

Use custom output and sorting when troubleshooting CPU, memory, or process relationships.
