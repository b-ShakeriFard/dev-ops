## Quick Cheat Sheet

| Signal | Number | Typical Meaning |
|---|---:|---|
| `SIGHUP` | 1 | Reload / terminal hangup |
| `SIGINT` | 2 | Interrupt |
| `SIGQUIT` | 3 | Quit |
| `SIGKILL` | 9 | Force termination |
| `SIGTERM` | 15 | Graceful termination |
| `SIGSTOP` | 19 | Pause process |
| `SIGCONT` | 18 | Resume process |

List all signals:

```bash
kill -l
```

## Overview

A signal is a small message sent to a process.

It can request actions such as:

```text
Stop
Terminate
Reload
Pause
Continue
```

Signals may come from:

- The user
- Another process
- The shell
- The kernel

---

## Common Signals

### SIGTERM

Default signal sent by:

```bash
kill PID
```

It asks the process to shut down cleanly.

---

### SIGKILL

```bash
kill -9 PID
```

The kernel terminates the process immediately.

The process cannot catch or ignore this signal.

---

### SIGINT

Usually generated by:

```text
Ctrl+C
```

Used to interrupt a foreground process.

---

### SIGSTOP / SIGCONT

Pause:

```bash
kill -STOP PID
```

Resume:

```bash
kill -CONT PID
```

---

### SIGHUP

Traditionally means terminal hangup.

Many daemons also use it to reload configuration:

```bash
kill -HUP PID
```

Behavior depends on the application.

---

## Sending Signals

By number:

```bash
kill -15 1234
```

By name:

```bash
kill -TERM 1234
```

Using `pkill`:

```bash
pkill -TERM nginx
```

## Practical Examples

Gracefully stop:

```bash
kill 1234
```

Force termination:

```bash
kill -9 1234
```

Pause:

```bash
kill -STOP 1234
```

Resume:

```bash
kill -CONT 1234
```

Check process afterward:

```bash
ps -p 1234 -o pid,stat,cmd
```

---

## Common Pitfalls

### Assuming Every Signal Has the Same Effect

Applications can handle signals differently.

For example:

```text
SIGHUP
```

may reload one daemon but terminate another.

### Jumping Straight to SIGKILL

Prefer:

```bash
SIGTERM
```

first.

`SIGKILL` should usually be the last resort.

## Conclusion

Signals are the standard Linux mechanism for controlling process behavior.

The most important ones to remember are:

```text
SIGTERM → graceful stop
SIGKILL → forced stop
SIGINT  → interrupt
SIGHUP  → often reload
SIGSTOP → pause
SIGCONT → resume
```
