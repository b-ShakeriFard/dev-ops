## Quick Cheat Sheet

| Command / Key | Purpose |
|---|---|
| `vi FILE` | Open file |
| `i` | Insert before cursor |
| `a` | Insert after cursor |
| `Esc` | Return to Normal mode |
| `:w` | Save |
| `:q` | Quit |
| `:wq` | Save and quit |
| `:q!` | Quit without saving |
| `dd` | Delete current line |
| `yy` | Copy current line |
| `p` | Paste |
| `/text` | Search forward |

## Overview

`vi` is a terminal-based text editor available on almost every Unix-like system.

Its biggest difference from editors such as `nano` is that it uses **modes**.

---

## vi Modes

The two essential modes are:

```text
Normal Mode
    ↓
Navigation and commands

Insert Mode
    ↓
Typing and editing text
```

When `vi` starts, you are normally in:

```text
Normal Mode
```

Press:

```text
i
```

to enter Insert mode.

Press:

```text
Esc
```

to return to Normal mode.

---

## Opening Files

Open:

```bash
vi file.txt
```

Edit a privileged file:

```bash
sudo vi /etc/hosts
```

Open at a specific line:

```bash
vi +25 file.txt
```

---

## Basic Movement

In Normal mode:

```text
h → left
j → down
k → up
l → right
```

Other useful commands:

```text
0  → beginning of line
$  → end of line
gg → first line
G  → last line
```

## Saving and Exiting

Return to Normal mode:

```text
Esc
```

Then:

```text
:w
```

Save.

```text
:q
```

Quit.

```text
:wq
```

Save and quit.

```text
:q!
```

Quit and discard changes.

## Searching

Search forward:

```text
/error
```

Press:

```text
n
```

for next match.

Search backward:

```text
?error
```

## Practical Examples

Edit SSH configuration:

```bash
sudo vi /etc/ssh/sshd_config
```

Workflow:

```text
vi file
   ↓
Press i
   ↓
Edit text
   ↓
Press Esc
   ↓
:wq
```

Replace text:

```text
:%s/old/new/g
```

This replaces every occurrence of `old` with `new`.

## Common Pitfalls

### Cannot Type Anything

You are probably in Normal mode.

Press:

```text
i
```

### Cannot Exit

Press:

```text
Esc
```

then:

```text
:q
```

or:

```text
:q!
```

### Accidentally Running Commands

Typing while in Normal mode may trigger editor commands rather than insert text.

Always check which mode you are in.

## Conclusion

The minimum `vi` survival kit is:

```text
i    → start typing
Esc  → stop typing
:wq  → save and quit
:q!  → quit without saving
```

Once those are comfortable, `vi` becomes far less intimidating.
