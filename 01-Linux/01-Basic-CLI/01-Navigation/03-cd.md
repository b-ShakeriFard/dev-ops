## Quick Cheat Sheet

| Command | Purpose |
|---|---|
| `cd DIR` | Enter directory |
| `cd ..` | Move to parent |
| `cd ../..` | Move up two levels |
| `cd ~` | Go to home directory |
| `cd` | Also go to home directory |
| `cd -` | Return to previous directory |
| `cd /` | Go to root directory |
| `cd ./DIR` | Enter relative directory |

---

## Overview

`cd` means:

```text
Change Directory
```

It changes the shell's current working directory.

Example:

```bash
cd /var/log
```

Verify with:

```bash
pwd
```

---

## Basic Usage

Enter a directory:

```bash
cd /etc
```

Move into a subdirectory:

```bash
cd nginx
```

Move up one level:

```bash
cd ..
```

Move up two levels:

```bash
cd ../..
```

---

## Special Paths

Home directory:

```bash
cd ~
```

or simply:

```bash
cd
```

Previous directory:

```bash
cd -
```

Root directory:

```bash
cd /
```

Current directory:

```text
.
```

Parent directory:

```text
..
```

---

## Absolute vs Relative Paths

Absolute paths start from `/`:

```bash
cd /var/log
```

Relative paths start from your current location:

```bash
cd ../log
```

Example:

```text
Current directory:
/var/www

Command:
cd ../log

Result:
/var/log
```

## Practical Examples

Move to your SSH directory:

```bash
cd ~/.ssh
```

Move back:

```bash
cd -
```

Enter a directory containing spaces:

```bash
cd "My Documents"
```

or:

```bash
cd My\ Documents
```

Move to a user's home directory:

```bash
cd ~alice
```

## Common Pitfalls

### Directory Does Not Exist

Example:

```text
bash: cd: test: No such file or directory
```

Check:

```bash
ls
```

### Permission Denied

You need execute permission on directories you traverse.

Example:

```text
bash: cd: /secure: Permission denied
```

Check:

```bash
ls -ld /secure
```

### `sudo cd` Does Not Work

`cd` is a shell builtin.

This:

```bash
sudo cd /root
```

will not change your current shell directory.

Instead:

```bash
sudo -i
cd /root
```
