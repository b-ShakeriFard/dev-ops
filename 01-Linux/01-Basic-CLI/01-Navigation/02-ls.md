## Quick Cheat Sheet

| Command | Purpose |
|---|---|
| `ls` | List directory contents |
| `ls -l` | Long format |
| `ls -a` | Include hidden files |
| `ls -h` | Human-readable sizes |
| `ls -lah` | Common detailed view |
| `ls -t` | Sort by modification time |
| `ls -S` | Sort by size |
| `ls -R` | Recursive listing |

---

## Overview

`ls` shows files and directories.

Basic usage:

```bash
ls
```

List another directory:

```bash
ls /var/log
```

A very common command is:

```bash
ls -lah
```

which shows detailed information, including hidden files and readable file sizes.

## Common Options

Long format:

```bash
ls -l
```

Include hidden files:

```bash
ls -a
```

Human-readable sizes:

```bash
ls -lh
```

Sort newest first:

```bash
ls -lt
```

Sort by size:

```bash
ls -lS
```

Reverse sorting:

```bash
ls -lr
```

---

## Long Listing Format

Example:

```text
-rw-r--r-- 1 alice developers 2048 Sep 13 10:20 app.log
```

Fields include:

```text
-rw-r--r--  → permissions
1           → link count
alice       → owner
developers  → group
2048        → size
Sep 13      → date
10:20       → time
app.log     → filename
```

## Practical Examples

List `/etc`:

```bash
ls /etc
```

Show everything:

```bash
ls -lah
```

Show newest files first:

```bash
ls -lt
```

Show largest files first:

```bash
ls -lhS
```

List one file:

```bash
ls -l /etc/hosts
```

List directories themselves rather than their contents:

```bash
ls -ld /var/log
```

---

## Hidden Files

Linux hidden files begin with:

```text
.
```

Examples:

```text
.bashrc
.profile
.ssh
```

Show them with:

```bash
ls -a
```

---

## Common Pitfalls

### `ls -l DIR` vs `ls -ld DIR`

This:

```bash
ls -l /var/log
```

lists the contents.

This:

```bash
ls -ld /var/log
```

shows information about the directory itself.

### File Size vs Disk Usage

`ls -lh` shows file size.

For actual disk usage, use:

```bash
du -h
```
