## Quick Cheat Sheet

| Command | Purpose |
|---|---|
| `mv SRC DEST` | Move or rename |
| `mv FILE DIR/` | Move file into directory |
| `mv -i SRC DEST` | Ask before overwrite |
| `mv -v SRC DEST` | Verbose output |
| `mv -n SRC DEST` | Do not overwrite |
| `mv -f SRC DEST` | Force overwrite |

---

## Overview

`mv` means:

```text
move
```

It is used for two main tasks:

```text
Move a file or directory
        +
Rename a file or directory
```

Basic syntax:

```bash
mv SOURCE DESTINATION
```

---

## Moving Files

Move a file into another directory:

```bash
mv notes.txt /tmp/
```

Move several files:

```bash
mv file1.txt file2.txt /tmp/
```

The final argument must be a directory when moving multiple files.

---

## Renaming Files

Rename:

```bash
mv old.txt new.txt
```

This does not create a copy.

The original name disappears and the file now exists as:

```text
new.txt
```

---

## Moving Directories

Move a directory:

```bash
mv project /opt/
```

Rename a directory:

```bash
mv project project-old
```

Unlike `cp`, no recursive option is required.

---

## Useful Options

Ask before overwriting:

```bash
mv -i file.txt destination/
```

Do not overwrite existing files:

```bash
mv -n file.txt destination/
```

Show what is happening:

```bash
mv -v file.txt destination/
```

Force overwrite:

```bash
mv -f file.txt destination/
```

Use `-f` carefully.

---

## Practical Examples

Rename a configuration backup:

```bash
mv nginx.conf nginx.conf.old
```

Move logs:

```bash
mv *.log /tmp/logs/
```

Move and rename at the same time:

```bash
mv app.conf /etc/myapp/app.conf
```

---

## Common Pitfalls

### Accidentally Overwriting

This:

```bash
mv file.txt existing.txt
```

may replace `existing.txt`.

Safer:

```bash
mv -i file.txt existing.txt
```

### Moving Into the Wrong Directory

Verify first:

```bash
pwd
ls
```

### Confusing mv with cp

`cp`:

```text
keeps the original
```

`mv`:

```text
moves or renames the original
```

## Conclusion

The essential patterns are:

```bash
mv FILE DIR/
mv OLD NEW
mv DIR NEW-DIR
```

Use `-i` or `-n` when you want to avoid accidental overwrites.
