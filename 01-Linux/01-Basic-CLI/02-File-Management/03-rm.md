## Quick Cheat Sheet

| Command | Purpose |
|---|---|
| `rm FILE` | Remove file |
| `rm FILE1 FILE2` | Remove multiple files |
| `rm -r DIR` | Remove directory recursively |
| `rm -i FILE` | Ask before removal |
| `rm -v FILE` | Show removed files |
| `rm -f FILE` | Force removal |
| `rm -rf DIR` | Force recursive removal |

---

## Overview

`rm` means:

```text
remove
```

Basic syntax:

```bash
rm FILE
```

Example:

```bash
rm notes.txt
```

Unlike graphical desktop environments, files removed with `rm` normally do not go to a recycle bin.

---

## Removing Files

Remove one file:

```bash
rm file.txt
```

Remove multiple files:

```bash
rm file1.txt file2.txt
```

Using wildcards:

```bash
rm *.log
```

Always verify wildcard matches before deleting:

```bash
ls *.log
```

---

## Removing Directories

`rm` does not remove directories by default.

Use:

```bash
rm -r project/
```

`-r` means:

```text
recursive
```

It removes the directory and everything inside it.

---

## Useful Options

Interactive confirmation:

```bash
rm -i file.txt
```

Verbose output:

```bash
rm -v file.txt
```

Force removal:

```bash
rm -f file.txt
```

Recursive and force:

```bash
rm -rf directory/
```

This is powerful and should be used carefully.

---

## Practical Examples

Remove old log files:

```bash
rm *.old
```

Delete an empty test file:

```bash
rm test.txt
```

Remove an entire temporary directory:

```bash
rm -r /tmp/my-test/
```

Safer recursive removal:

```bash
rm -ri project/
```

---

## Common Pitfalls

### Dangerous Wildcards

Be careful with commands such as:

```bash
rm -rf *
```

Always check your current directory first:

```bash
pwd
ls
```

### Confusing `rm` and `rmdir`

`rm -r` can remove directories containing files.

`rmdir` only removes empty directories.

### Using `-f` Unnecessarily

`-f` suppresses prompts and many errors.

Use it only when you know exactly what will be removed.

## Conclusion

The essential forms are:

```bash
rm FILE
rm -i FILE
rm -r DIR
```

Treat `rm -rf` as a high-risk command and verify the path before running it.
