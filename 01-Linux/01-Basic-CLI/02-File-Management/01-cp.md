## Quick Cheat Sheet

| Command | Purpose |
|---|---|
| `cp SRC DEST` | Copy file |
| `cp FILE DIR/` | Copy file into directory |
| `cp -r SRC DEST` | Copy directory recursively |
| `cp -i SRC DEST` | Ask before overwrite |
| `cp -v SRC DEST` | Verbose output |
| `cp -p SRC DEST` | Preserve mode, ownership, timestamps |
| `cp -a SRC DEST` | Archive-style copy |

## Overview

`cp` means:

```text
copy
```

Basic syntax:

```bash
cp SOURCE DESTINATION
```

Example:

```bash
cp notes.txt backup.txt
```

This creates a copy while leaving the original file unchanged.

---

## Copying Files

Copy and rename:

```bash
cp file.txt file-backup.txt
```

Copy into another directory:

```bash
cp file.txt /tmp/
```

Copy several files:

```bash
cp file1.txt file2.txt /tmp/
```

The final argument must be a directory when copying multiple files.

---

## Copying Directories

Directories require recursive copying:

```bash
cp -r project project-backup
```

Without `-r`, `cp` will normally refuse to copy a directory.

---

## Useful Options

Interactive mode:

```bash
cp -i file.txt backup.txt
```

Verbose mode:

```bash
cp -v file.txt /tmp/
```

Preserve timestamps and permissions:

```bash
cp -p file.txt backup.txt
```

Archive mode:

```bash
cp -a project project-backup
```

`-a` is commonly used when you want to preserve directory structure and metadata.

---

## Practical Examples

Backup a configuration file:

```bash
sudo cp /etc/ssh/sshd_config \
/etc/ssh/sshd_config.bak
```

Copy all `.conf` files:

```bash
cp *.conf /tmp/config-backup/
```

Copy hidden and normal contents of a directory:

```bash
cp -a source/. destination/
```

## Common Pitfalls

### Accidentally Overwriting a File

This may replace `backup.txt`:

```bash
cp file.txt backup.txt
```

Use:

```bash
cp -i file.txt backup.txt
```

when unsure.

### Forgetting `-r`

Wrong for directories:

```bash
cp project backup
```

Use:

```bash
cp -r project backup
```

### Confusing Directory Contents

These can behave differently:

```bash
cp -r source destination
```

and:

```bash
cp -a source/. destination/
```

The second explicitly copies the contents of `source`.

## Conclusion

The essential patterns are:

```bash
cp FILE DEST
cp FILE DIR/
cp -r DIR DEST
```

Use `-i` for safety and `-a` when preserving directory metadata matters.
