## Quick Cheat Sheet

| Command | Purpose |
|---|---|
| `journalctl` | View systemd journal |
| `ls /var/log` | List log files |
| `tail -f FILE` | Follow log live |
| `less FILE` | Read large log file |
| `grep TEXT FILE` | Search log content |
| `dmesg` | View kernel messages |

## Overview

Linux logs record events generated by:

```text
Kernel
Services
Applications
Authentication
Networking
System tools
```

A useful mental model is:

```text
Application / Kernel
        ↓
Logging system
        ↓
Journal or log file
        ↓
Administrator investigates
```

---

## Main Logging Sources

### systemd Journal

Modern distributions commonly use `systemd-journald`.

Query with:

```bash
journalctl
```

Service-specific logs:

```bash
journalctl -u sshd
```

---

### Syslog

Traditional logging commonly uses:

```text
rsyslog
```

It may write messages to files under:

```text
/var/log
```

---

### Application Logs

Applications may maintain their own files.

Examples:

```text
/var/log/nginx/
/var/log/httpd/
/var/log/mysql/
```

Exact locations depend on the application and distribution.

---

## Important Log Locations

Common examples:

```text
/var/log/messages
/var/log/syslog
/var/log/auth.log
/var/log/secure
/var/log/cron
/var/log/audit/
```

Typical distribution differences:

```text
Ubuntu/Debian:
  /var/log/syslog
  /var/log/auth.log

RHEL/Rocky:
  /var/log/messages
  /var/log/secure
```

---

## systemd Journal vs Log Files

The journal is queried with:

```bash
journalctl
```

Traditional logs can be read with:

```bash
less /var/log/messages
```

A system may use both at the same time.

---

## Practical Examples

Recent system errors:

```bash
journalctl -p err
```

Follow SSH logs:

```bash
journalctl -u sshd -f
```

Search traditional logs:

```bash
grep -i error /var/log/messages
```

Follow a file:

```bash
tail -f /var/log/syslog
```

## Conclusion

Linux logging is not one single system.

Logs may come from:

```text
systemd journal
syslog
kernel
applications
```

The key skill is knowing where to look and how to filter the information quickly.
